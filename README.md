# Advanced Algorithmic Techniques (TAIS) - UCM

This repository contains my solutions to the weekly online judge algorithmic challenges for the **Software Engineering Algorithmic Techniques (TAIS)** course at Universidad Complutense de Madrid (UCM).

The exercises focus on the design, analysis, and implementation of efficient data structures and advanced algorithms to solve complex computational problems.

## 💻 Tech Stack
*   **Language:** [C++]
*   **Environment:** UCM Online Judge

## 🎯 Key Focus
*   **Algorithmic Efficiency:** Strict focus on optimizing both time and space complexity (Big O notation) to meet the tight execution time limits of the online judge.
*   **Complexity Analysis:** Solutions include a breakdown of their theoretical cost and the reasoning behind the chosen data structures (e.g., O(V + E) for graph traversals, O(N log N) for priority queues).
	
## 📚 Course Syllabus & Solutions

*   **[Week 1]** Advanced Search Trees (BST, AVL Trees)
*   **[Week 2]** Priority Queues and Heaps
*   **[Week 3]** Heapsort and Variable Priority Queues
*   **[Week 4]** Undirected Graphs and Traversals (BFS, DFS)
*   **[Week 5]** Directed Graphs and Traversals (Topological Sort)
*   **[Week 6]** Disjoint Sets, Weighted Graphs, and Minimum Spanning Trees (Prim, Kruskal)
*   **[Week 7]** Weighted Digraphs and Shortest Path Algorithms (Dijkstra)

## 📝 Note on Problem Statements
While all the code, variable names, and documentation in this repository are written in English, the original problem statements provided by the online judge are in Spanish.
